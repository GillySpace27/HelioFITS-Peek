# Keyboard and mouse

In the Quick Look preview and the viewer's image:

| Keys or gesture | What it does |
|---|---|
| Hover | Pixel value and helioprojective coordinate |
| Drag a box | Region statistics and histogram |
| Scroll, ↑ ↓ (also → ←) | Blink between layers |
| ⌥ + arrow | Move the readout cursor |
| ⌥⇧ + arrow | Measure a box from the readout cursor |
| ⌘ added to the two above | Finer steps |
| Esc | Clear the readout cursor and box |
| ⌥← ⌥→ | Move the swipe divider, when one is showing |
| ⌥-scroll, ⌘+ ⌘− ⌘0 | Zoom in, out, and back to fit |
| ⌘C | Copy the pixel readout |

In the app:

| Keys | What it does |
|---|---|
| ⌘O | File ▸ Open… (a FITS file, or a folder) |
| ⇧⌘R | File ▸ Show in Finder |
| ⌥⌘C | File ▸ Copy Path (Finder's own shortcut for Copy as Pathname) |
| ⌘, | Settings |
| ⌘F | Search the header, in the viewer |
