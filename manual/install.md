# Installing

HelioFITS Peek runs on any Mac with macOS 14.5 or later, Apple Silicon or Intel (it is a universal
binary). **[Get it on the Mac App Store](https://apps.apple.com/app/id6790952544).**

## The first launch

Opening the app with no file shows the viewer's empty window, a drop zone: drop a FITS file on
it, or click **Open…** (⌘O). Beside it, the **Welcome** window confirms the extensions are
installed and offers **Open a Finder Window…**, **Open in Viewer…** and **Getting Started**.
Tick **Don't show this again** to keep Welcome away; **Help ▸ Welcome to HelioFITS Peek** brings
it back. When the build carries the bundled samples, **Try a Sample** opens one and **Put Samples
in a Folder…** copies them somewhere you choose, so there is something to press the spacebar on.

New thumbnails and previews can take a minute to appear in Finder the first time.
